# September 11, 2026 source and data snapshot

This snapshot brings the local farmer work into the private GitHub repository.
It includes source, tests, tools, all saved route variants, calibrated memory
profiles, documentation, historical development utilities and selected
structured performance/loot/banking reports. The publication does not restart
or change the running game. Older dated documents describe earlier milestones;
this handoff and AGENTS.md describe the current state and standing preferences.

## Running on another PC

Install the game separately, use Python 3.12 or later, and follow the environment
setup in the README. Before starting the desktop app, copy the example profile:

```powershell
Copy-Item profiles/desktop-foreground.example.yaml profiles/desktop-foreground.local.yaml
.\.venv\Scripts\pythonw.exe scripts/start_desktop_app.py
```

The example preserves current calibration/preferences, but is not a promise of
compatibility with a different client build, resolution or installation path.
Use the memory validation and wrapper setup documentation. Configure game login
and Discord credentials locally; their encrypted files are deliberately absent.
GitHub stores a snapshot, not a hosted farmer or a live synchronization service.

## Current behavior and limits

- All gameplay observations must use read-only memory. Legacy visual tools and
  template assets remain historical code, not authorization to use vision.
- The route lifecycle now keeps life care active and replans after the two
  known movement-stall errors. Manual Stop and uncertain transactions remain
  terminal; purchasing/deposit operations are not blindly retried.
- Phoenix and Market movement use checked paths, alternate landings, short-run
  obstruction recovery and fresh warehouse reachability checks.
- Scatter ranks no longer have a hardcoded level ceiling. Skill identity,
  stable reads and supported range limits are still required.
- Loot policy keeps Super, verified + equipment, Meteors and Dragonballs.
  Currency and Elite-only +0 gear are excluded. Carried +2/Dragonball triggers
  immediate banking; equipped valuable gear does not trigger a trip.
- Refill targets are five selected potions and at most ten physical arrow
  packs. Return for fewer than three usable arrows with no reserve, exhausted
  healing supplies or full inventory; valuable banking remains independent.
- Town/Market storage, ten-Meteor consolidation, return travel and full-storage
  halt are implemented, but navigation can still need recovery. No zero-death
  guarantee or sustained throughput guarantee has been established.
- The north/center/south route comparison was interrupted by banking trouble;
  there is no qualified comparison winner. A strong short northern-field sample
  is preliminary evidence, not proof of sustained full-loop performance.

## Data included and excluded

`data/snapshots/2026-09-11/manifest.json` lists archived reports and exclusions.
The archive contains timestamped pickup history, performance experiments,
banking/runback evidence, hourly verified-kill totals and selected validation reports. These are historical
observations, not current status; some contain obsolete coordinates or IDs.
Authentication fields, webhook URLs and possible runtime-token strings are
redacted. Bulk SQLite/event logs, raw process dumps, screenshots, user videos,
runtime control state, dependencies and credentials remain on the original PC.

`docs/development-archive/*.py.txt` preserves one-off development scripts as text.
Do not execute them without review: several encode stale process IDs, positions,
control revisions or one-time recovery actions. Supported code is in `src/` and
`scripts/`.

## Validation

The publication snapshot passed **1,181 tests in 47.91 seconds** with
`python -m pytest -q`. The first full run exposed a test dependency on a private
local profile and an outdated warehouse test fixture. The range test now uses
the tracked example profile, and the overflow fixture supplies the current
vendor-reachability response. No gameplay logic changed during publication.
Tests do not establish unattended safety.
