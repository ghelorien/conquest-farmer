- Isometric click point = anchor + ((dx − dy)·32, (dx + dy)·16), where dx, dy
  is the tile delta and anchor is the farmer's on-screen foot point (about
  (700,418) in a 1036×793 client).

  0x5e12d0, uid +0x78, name +0xA4, tile +0xE8, client draw point +0xF8.
  uid < 1,000,000 is an NPC.

## 6. How to operate

### Build a release
Use a clean shell: `PYTHONPATH` **must be unset**. With it set, r57 and r59
came out broken.

```powershell
$env:PYTHONPATH=$null
$w="C:\Users\Floor\Documents\ChatGPT\cf-smooth"   # or any clean checkout of main
$py="C:\Users\Floor\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe"
& $py "$w\scripts\release.py" build $w "C:\Users\Floor\Documents\ChatGPT\Conquest-releases" 2026.09.26-smooth-r67 --data-root "C:\Users\Floor\AppData\Local\Packages\OpenAI.Codex_2p2nqsd0c76g0\LocalCache\Local\Conquest"
```

Then verify:
- 40 folders in `.venv\Lib\site-packages`;
- `win32\win32api.pyd` exists;
- `.venv\Scripts\python.exe -c "import win32api, numpy, pydantic, yaml, conquest.desktop_app"`.

### Deploy or roll back
Always with the user's go-ahead, and only at a safe point (not mid-trade,
mid-delivery or mid-travel).
1. The farmer must be Off, alive, and in Market or Phoenix. No merchant input
   owner or handoff, and no open merchant transaction.
2. `ops/live-helpers/deploy_stop.py` does an explicit Farming Off and writes
   `deploy-stop-<release>.json`.
3. Run `ops/live-helpers/restart_release.py <release-id> [--no-farming]`
   **elevated** (`Start-Process -Verb RunAs`). It closes the controller
   normally, clears only its own deploy Stop marker, and runs `start_r51.py`,
   which launches the release and switches Farming On once unless
   `--no-farming` is given.
4. Rollback is the same command with the previous release id (r65 now).

### Park in Market for supervised work
`ops/live-helpers/park_market.py` (elevated). It requires Farming On with a
fresh observation, the route hunting, and no town trip or merchant work.
It pauses Farming, stops the route with its own tagged Stop marker, parks in
Phoenix city, and takes the Conductress to Market. From the far field this
takes about 10 min. `park_watch.py [wait] [event]` waits for an event such as
`town_visit_completed`, when the farmer is near the city, then runs it.

### Read-only checks
All in `ops/live-helpers/`:
- `refill_results.py`, `refill_health.py`, `merchant_state.py`: listed
  counts, bag, blockers, lock holder.
- `market_moves.py [since-epoch]`: click success per action and distance.
- `journal_events.py`, `open_tx.py`, `db_history.py`: merchant journal.
- `delivery_probe_read.py`, `ingress_check.py`: the delivery-target probe
  and path through the crowd.

The scripts hard-code this PC's paths and ids of 09-26; copy them to
`cf-release-src\.runtime` to run them.
